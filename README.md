# Student Grade Tracker – Java

## 📌 Project Overview
The Student Grade Tracker is a simple Java-based application designed to manage student marks and generate academic performance reports.

It accepts student details and subject marks, calculates average scores, identifies the highest and lowest marks, and assigns grades based on student performance.

## 🎯 Objectives
- To manage student marks efficiently.
- To calculate average marks.
- To identify highest and lowest marks.
- To generate student grade reports.

## ✨ Features
- Input student names.
- Enter marks for three subjects.
- Calculate average marks.
- Find highest and lowest marks.
- Automatically assign grades.
- Display a student performance report.

## 🛠️ Technologies Used
- Programming Language: Java
- Concepts: ArrayList, Loops, Conditional Statements
- IDE: Visual Studio Code
- JDK: Java Development Kit

## ⚙️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Compile the Java program:

```bash
javac StudentGradeTracker.java
```

5. Run the program:

```bash
java StudentGradeTracker
```

## 📊 Grade Criteria

| Average Marks | Grade |
|---|---|
| 90 – 100 | A |
| 75 – 89 | B |
| 50 – 74 | C |
| Below 50 | Fail |
